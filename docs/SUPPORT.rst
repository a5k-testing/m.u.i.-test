=======
Support
=======

The best way to get support is to open an Issue_ here on GitHub or to post in the `official support thread`_ on the XDA forum.

Before asking for help, please:

1. Read the `installation instructions <./INSTRUCTIONS.rst>`_ carefully.
2. Search the `existing issues <https://github.com/micro5k/microg-unofficial-installer/issues>`_ to see if your problem has already been reported.
3. Check the `official support thread`_ on XDA for known solutions.

Reporting a bug
===============

When opening a new issue, please include as much of the following information as possible:

- **Android version** and device model.
- **Recovery version** (if flashing via TWRP) or the method used (ADB sideload, ``zip-install.sh``).
- **Installer version** (e.g. ``1.3.2-beta``).
- The **debug log** produced during installation (located at ``/sdcard/microg-unofficial-installer-logs/`` or printed on screen).
- A clear description of the problem and the steps to reproduce it.

The more detail you provide, the faster we can help you.
